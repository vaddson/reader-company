# reader

Консольный RAG-помощник по markdown-книге: прочитывает книгу, строит
перманентный индекс в SQLite и отвечает на вопросы по её содержанию.

Стек: Python 3.14 · Ollama (LLM + локальные эмбэддинги) · SQLite.
Зависимости — только `requests`.

## Запуск

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
```

### 1. Индексация книги

```bash
.venv/bin/python main.py index ../books/AI-Agents-in-Depth-RU-v1.2.md --db book.db
```

- разбивает markdown на чанки вдоль заголовков (цель ≈ 3000 симв.,
  overlap ~15%, к каждому чанку сохраняется путь раздела «Глава > раздел»);
- векторизует эмбэддинговой моделью (`$RAG_EMBED_MODEL`, по умолчанию
  `qwen3-embedding:8b`);
- сохраняет в указанный файл SQLite — индекс переносим, живёт между запусками.

Повторный запуск по той же книге пересобирает индекс заново.

### 2. Вопросы (REPL)

```bash
.venv/bin/python main.py ask --db book.db
```

- введите вопрос; ответ печатается в консоль;
- если модель решит, что вопрос размыт, она задаст **уточняющий вопрос** —
  ответьте на него (промпт `?`), ответ будет сформулирован с учётом уточнения;
- команды: `/hits` (показать найденные фрагменты), `/reset` (сброс диалога),
  `/exit`.

## Настройка

Переменные окружения:

| Переменная       | По умолчанию         | Назначение                |
|------------------|----------------------|---------------------------|
| `OLLAMA_HOST`    | `http://localhost:11434` | адрес Ollama           |
| `RAG_LLM_MODEL`  | `qwen3.8:27b`        | модель генерации (можно `--model`) |
| `RAG_EMBED_MODEL`| `qwen3-embedding:8b` | модель эмбэддингов        |

## Как это устроено

```
ввод вопроса
  → rag/retriever.py: эмбэд вопроса, top-k по косинусу (SQLite)
  → rag/llm.py:      /api/chat (format=json), модель отвечает
                     {"type": "answer"|"clarify", "text": "..."}
  → main.py:         печатает ответ или уточняющий вопрос и ждёт ввод
```

- `rag/mdchunks.py` — разбор markdown: ATX-заголовки, плюс «книжные»
  заголовки (оглавление как канонический список разделов на случай
  переформатированных из PDF книг), защита от комментариев/строк в коде.
- `rag/db.py` — схема: `chunks(doc, seq, heading_path, text, embedding BLOB)`
  и `meta`.
